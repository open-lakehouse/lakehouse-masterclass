# 📖 Course contents

The textbook builds one local lakehouse in dependency order. Each chapter introduces a layer, adds it to the running system, and ends with a checkpoint. Read the chapters in sequence because later chapters use services and files created earlier.

For a compact map of commands and checkpoints, see [`COURSE.md`](../COURSE.md).
